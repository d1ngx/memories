# Memories for KodBox

完整安装、依赖插件、Docker 部署和排错步骤见 [INSTALL.md](INSTALL.md)。

这是一个面向 KodBox 的原生适配，不是把 Nextcloud 应用原样复制进来。它复用了 Memories 的核心产品思路，并改写了文件、权限、路由、数据库与后台任务边界。

## 功能

- 扫描当前用户个人空间中的图片和视频
- 优先读取 JPEG EXIF 拍摄时间、尺寸和 GPS，缺失时回退到文件修改时间
- 参考 Nextcloud Memories 的时间线、搜索、文件夹、收藏、人物、归档、当年今日、地图和标签导航
- 支持按文件名、中文/原始智能标签和人物名称搜索
- 媒体卡片可直接收藏、归档或加入相册；相册支持创建、重命名、浏览、移除项目和删除
- 智能标签卡片页，可从标签封面直接进入对应图片列表
- 分栏式 Memories 设置弹窗，支持网格、文件名、标签、自动播放和高清加载偏好
- 分页与懒加载缩略图
- 与 `recognize` 插件共享本地对象/地标智能标签、人脸检测和人物聚类
- 人物卡片支持用户自定义名称；中文界面会翻译 Recognize 通用对象标签，数据库仍保留原始标签以保证筛选兼容
- MySQL 与 SQLite 数据表
- 每 15 分钟增量索引计划任务

启用插件后，从左侧菜单进入“回忆”，点击“更新索引”即可首次建库。缩略图和更多图片格式建议同时启用 KodBox 自带的 `fileThumb` 插件。

## 与 Nextcloud Memories 的差异

当前版本提供当前用户私有相册，但没有移植 Nextcloud 专属的 DAV 公共/协作相册、Nextcloud 分享、地点反向地理编码、Live Photo/HLS 和相册协作协议。这些能力依赖 Nextcloud 的文件节点、系统标签和 DAV 接口，不能安全地直接映射到 KodBox。人物功能使用 KodBox 独立的人脸与聚类表实现，不依赖 DAV。
